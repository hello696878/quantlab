# QuantLab — Milestone History (Phase 40.0)

Project history by major capability — the narrative version of the tag list.
Per-phase detail: [`ROADMAP.md`](ROADMAP.md); grouped changes:
[`../CHANGELOG.md`](../CHANGELOG.md). Throughout every milestone the ground
rules never changed: **deterministic educational platform, local-first demo
focus, no live trading, not investment advice, not production
trading/risk/compliance infrastructure.**

1. **Initial quant lab foundation** (phases 0–11 → v4.0.0) — FastAPI backend
   MVP with a lookahead-safe, cost-aware backtest engine; six strategies;
   Next.js neon-terminal frontend; local SQLite persistence; Docker + CI.
2. **Core portfolio / backtest / strategy workflow** — parameter sweep,
   train/test, walk-forward; portfolio backtest/optimization/frontier/risk
   dashboard/stress/factors; CSV backtests; no-code strategy builder; saved
   work + branded report export.
3. **Trust & content layer** (→ v4.7.0 showcase) — data-quality diagnostics,
   benchmark analytics, reproducible config hashes, robustness/stability
   labs; Strategy Library, Paper Replications ("inspired demos, not full
   replications"), Quant Disasters case studies.
4. **Derivatives & volatility expansion** (v4.8+) — Options Lab
   (Black-Scholes → trees → Monte Carlo → surfaces/SVI → Heston),
   Volatility Surface & Variance Swap Lab, Futures & Commodities Lab.
5. **Rates, credit, FX, real assets** — Yield Curve & Short Rate labs,
   Credit Risk (Merton/hazard/CDS), FX Lab, Real Estate + MBS prepayment,
   Event Lab; local LaTeX formula rendering platform-wide.
6. **Market microstructure & execution** — order-book analytics, execution
   schedules, TCA attribution, order-flow toxicity; Global Markets Globe
   data layer with opt-in fail-closed adapters; Cross-Sectional Scanner;
   AFML methodology lab.
7. **Crypto, DeFi, on-chain, tokenomics, alternative data, macro** — the
   six-lab deterministic suite, later upgraded with interactive shock
   sliders and local charts.
8. **Scenario & report workflow** (v4.50–v4.51) — Unified Scenario Studio
   (cross-lab impact scores + report builder) and the Research Workspace
   (experiment journal, reproducibility checks, exports).
9. **Product demo center** (v4.52) — guided walkthroughs, module health,
   audience-aware demo scripts.
10. **Data reliability center** (v4.53) — data-mode/provider/fixture
    registries; the deterministic-tests and fail-closed-provider story as a
    product surface.
11. **QA command center** (v4.54) — release-readiness scoring, smoke-test
    matrix, regression checklists, verification command checklist.
12. **Platform UX polish** (v4.55) — route error boundaries, grouped
    sidebar, starting paths, accessibility passes.
13. **Portfolio launch pack** (v4.56) — public README, pitches, screenshot/
    video/interview docs, in-app Portfolio Showcase.
14. **Local demo / developer onboarding** (v4.57) — environment doctor,
    safe helper scripts, onboarding guides and page.
15. **Version manifest / release center** (v4.58, this milestone) — version
    manifest, grouped changelog, release-notes template, extended release
    checklist, milestone history, project snapshot, in-app Release Notes
    Center.
